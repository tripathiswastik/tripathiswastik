### 🏛️ Pillar 1: Enterprise Oracle SCM & Mission-Critical Data Infrastructure
- **Supply Chain Planning Control**: Deep architecture knowledge of **Oracle EBS R12**, **Advanced Supply Chain Planning (ASCP)**, **Demantra Demand Management**, and **Value Chain Planning (VCP)** suites.
- **Dual-Stage ETL Architecture**: Mastery of data progression across **Source ADS** $\rightarrow$ **Snapshot Logs (`MLOG$_`)** $\rightarrow$ **Stage 1 Staging (`MSC_ST_*`)** $\rightarrow$ **Stage 2 ODS (`MSC_*`, `plan_id = -1`)** $\rightarrow$ **Stage 3 PDS (`plan_id > 0`)**.
- **Real-Time Lock Introspection & RAC Resiliency**: Engineering hierarchical lock trees over `V$SESSION`, `V$LOCK`, `V$LOCKED_OBJECT`, and `DBA_OBJECTS` using recursive `CONNECT BY PRIOR s.sid = s.blocking_session` across Oracle RAC clusters.
- **Fail-Closed Batch Remediation**: Pre-kill rollback evaluation via bind-variable queries on `(G)V$TRANSACTION` to protect database buffer cache, preventing unrecoverable rollback overhead and cascade stalls.

### 🤖 Pillar 2: Applied GenAI, Autonomous Agents & Edge Systems
- **Stateful Agentic Workflows**: Implementation of **LangGraph state machines** (`StateGraph`, `Command`, `interrupt()`, typed state reducers) with table-driven risk-tiered **Human-in-the-Loop (HITL)** governance.
- **Cryptographic Action Verification**: Action-bound ephemeral approval tokens with **SHA-256 state fingerprinting** (`{action}:{sid}:{serial}:{object}:{inst_id}`) and anti-replay registries preventing stale execution.
- **Domain Document Intelligence**: Automated continuous auditing with **IBM Granite 3.0/4.2** and **IBM Docling**, enforcing strict GHG Protocol Scope 1–3 mathematical reconciliation, refusal without hallucination, and statutory framework alignment (**SEBI BRSR Core**, **CSRD ESRS**, **SASB**).
- **Sub-50ms Streaming Edge Audio**: Multi-task causal chunk-based **WavLM** architectures with KV-cache persistence, **ArcFace angular hypersphere embeddings**, **Squeeze-and-Excitation CNNs**, and zero-lookahead static ONNX / NVIDIA TensorRT execution.
- **Agentic Evaluation Benchmarking**: Author of code-repair harnesses evaluated across frontier LLMs (Claude 3.5 Sonnet, GPT-4o, IBM Granite 3.0, Llama 3.3) measuring stateful repair, cent-precision tax math, and pass@1 rates.
